# Shadow-zet OS — Static Website

This repository contains a multi-page static website for Shadow-zet OS. It's an enterprise-grade, dark-themed site that explains the problems in modern IT and how Shadow-zet (an OS-level solution) addresses them.

Files:

- `index.html` — Home / overview
- `problems.html` — Real-world IT problems
- `failures.html` — Why current tools fail
- `architecture.html` — OS-level architecture explanation
- `labs.html` — Integrated cybersecurity labs
- `soc.html` — SOC / SIEM for SMBs
- `blue-team.html` — Blue-Team defense
- `certification.html` — Certification & workforce readiness
- `ethics.html` — Ethics and legal trust
- `deployment.html` — Deployment, cost, ROI
- `vision.html` — Long-term vision
- `investors.html` — Investor landing page
- `css/styles.css` — Shared styles
- `js/main.js` — Small JS helpers
- `assets/logo.svg` — Logo asset

How to view:

Open any of the `.html` files in your browser (for example `index.html`). No build step is required — this is a static site.

Notes:

- Content and structure follow a consistent Problem → Impact → Why Existing Solutions Fail → How Shadow-zet Solves It → Why an OS-Level Solution Is Necessary pattern on each page.
- The design avoids "hacker" stereotypes and targets decision-makers, engineers, educators, and investors.
